## Aturan singkat
- Teks di tombol oranye = Biru Malam, jangan putih.
- Latar terang pakai logo "latar-terang"; latar gelap pakai "latar-gelap".
- Folder 4 adalah potongan dari gambar board (resolusi sedang), cocok untuk referensi/moodboard, bukan untuk cetak.

## Langkah upload
1. Canva > Brand (Brand Kit) > Logo > Upload: isi folder 1-logo (dan maskot dari 2-maskot).
2. Warna > tambah satu per satu dari daftar hex di atas.
3. Font: Canva menolak .woff dan upload font butuh paket berbayar. Pakai font dari pustaka Canva. File di 7-font-file-untuk-web dipakai untuk website.
4. Folder 3 dan 4: unggah lewat Uploads sebagai referensi.

## Folder 6-elemen-satuan
Elemen dekoratif satuan, bertransparansi (PNG 3x; yang pure-bentuk juga ada SVG): bintang, lengkung, jendela terminal, prompt, tombol CTA (kuning dan Api Dupa), lencana paket, label LIAR/MANTRA, status, petir {}, kopi, server-awan, bar meter, ikon nilai, ikon layanan, footer.
Digambar ulang mengikuti board dan spesifikasi warna, jadi bentuknya mirip tapi bukan salinan piksel. Dirancang untuk latar gelap (#0B0E14).
Catatan: ikon aplikasi/favicon bersih dibuat dari monogram 193 px, jadi untuk cetak minta file vektor logo aslinya.
